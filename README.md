EXPMCS Project

Monte Carlo simulation framework for studying phase behaviour and thermodynamic properties of alloys using the EXPMCS codebase.

Contents

src/ — Java source code for phase models and Monte Carlo simulations.

bin/ — Compiled classes, if included.

config — Configuration file.

HEAD — Original project file.

Requirements

Java Development Kit (JDK)

Usage

Compile and run the required Java classes using the appropriate configuration and simulation parameters.
